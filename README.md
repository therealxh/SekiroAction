# Sekiro 风格动作战斗系统

> 基于 Unity 的第三人称动作战斗原型（独立开发）：从输入系统、状态机到战斗判定的完整战斗闭环。

## 项目概览

| 项 | 内容 |
|----|------|
| 引擎 / 技术栈 | Unity 2022.3 LTS · URP · C# · Input System |
| 代码规模 | 23 个脚本 · 约 1200 行 C# |
| 核心玩法 | 移动 / 三段连击 / 格挡 / 闪避（无敌帧）/ 锁敌 / 敌人 AI / 战斗 HUD |

## 核心系统

- **三层状态机架构**（Context / State / StateMachine）：玩家 7 状态、敌人 5 状态；转移逻辑集中于基类工具箱（区分边沿/电平输入的自我切换规则），新增状态零侵入
- **输入系统**：Input System 事件驱动（瞬时动作）+ 轮询（持续动作）双模式；缓冲-消费机制（防连发 / 跨帧不丢键 / 窗口前预输入）
- **三段连击**：连段计数跨状态存活、连段窗口按动画实测时长自适应、缓冲帧处理 Animator 时序
- **战斗判定框架**：BoxCast 扫掠判定（每刀触发一次，避免高速挥砍隧穿漏检）+ IDamageable 接口解耦 + 伤害过滤链（无敌帧 / 格挡免伤）+ 弹刀机制（判定结果驱动攻击方受击）
- **敌人 AI**：条件驱动状态机（待机 / 索敌追击 / 攻击 / 受击 / 死亡），含攻击冷却（时间戳差值）、脱战与受击回追逻辑
- **锁敌系统**：目标筛选 / 锁定切换 / 自动解锁；锁定态朝向与移动解耦（相对目标坐标系移动）
- **战斗 HUD**：运行时构建血条 / 架势条；架势累积-破防-衰减机制

## 操作说明

| 操作 | 按键 |
|------|------|
| 移动 | W / A / S / D |
| 攻击（三段连击） | 鼠标左键 |
| 格挡（按住） | 鼠标右键 |
| 闪避（无敌帧） | 空格 |
| 锁定 / 解锁目标 | 鼠标中键 |
| 重开场景 | R |

## 运行方式

1. 用 Unity 2022.3 LTS 打开项目
2. 打开场景 `Assets/Scenes/SampleScene`
3. Play 运行

## 架构说明

```
输入层     PlayerInputHandler（事件 + 轮询双模式）
              ↓ 缓冲 / 消费
上下文层   PlayerController / EnemyController（共享数据 · 配置 · 外部入口）
              ↓ ChangeState
状态机层   StateMachine + State 基类（转移工具箱）
              ↓ Update：物理速度 / 转向 / 动画参数
表现层     Animator（参数驱动动画状态机）
```

战斗数据流：攻击动画进度 50% → BoxCast 扫掠 → IDamageable.TakeDamage → 过滤链（无敌/格挡）→ 扣血 → 受击/死亡状态

## 已知边界

- 美术资源为免费占位素材（Mixamo 等），无音效
- 锁敌移动暂无 Strafe 专用动画（存在滑步）
- 项目定位：技术展示型原型，核心价值在系统架构与战斗逻辑的完整性
